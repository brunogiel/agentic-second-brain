# Repos de markdown, skills y agents

Para repos cuyo contenido principal es **markdown, skills, agents y workflows**, no una app web.

La diferencia que manda: a estos repos **los lee un modelo como instrucciones ejecutables**, no
una persona como interfaz. Un archivo ambiguo no genera un bug visible, genera comportamiento
distinto cada vez, que es mucho más caro de encontrar.

| # | Archivo | Qué cubre |
|---|---|---|
| 000 | `000-skill-structure.md` | Estructura de un SKILL.md, frontmatter, descripción con frases-gatillo |

Arrancá con este y sumá reglas solo cuando el repo te muestre que las necesita. Es mejor empezar
corto que sobre-estructurar de entrada.
